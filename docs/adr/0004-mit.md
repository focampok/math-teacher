# ADR 0004 — MIT license

**Status:** Accepted  
**Date:** 2026-09-11

## Context

The project is public and meant to be self-hosted (Railway or a laptop). Teachers and other SaaS operators should be able to run it without copyleft obligations.

## Decision

License the repository under MIT. Academic results are not guaranteed; the README states that explicitly.

## Consequences

- Someone may offer a closed hosted version. That is accepted.
- If a stronger share-alike guarantee is needed later, a new project (not a silent relicense of past contributions) would be required.
